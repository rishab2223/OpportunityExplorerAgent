Chat commands
llm: <instruction> ask the model to draft or redo the answer to the current question (one model call; bare llm: = fresh draft; plain text without the prefix is typed into the form as-is)
done the page is ready / you submitted the application yourself (also: applied, submitted, finished). Only at a hand-off prompt: at a question about one box, a reply is typed into that box - use i submitted there
i submitted record this as applied and end the session, from ANY prompt - including one asking about a single box, where done would be typed into it. For a site that asks for an emailed code after the form is sent, this is the way out (also: i applied, mark applied, or the I submitted it button)
next at "This step is filled in": click the wizard's Next for you (or click it yourself); auto next stops the agent asking for the rest of the session
llm: <question> at "This step is filled in" or "Review the form and click Submit": draft an answer for a question the form asked (paste the question, or part of it); the draft comes back for you to edit before it goes in. If the box cannot be found on the page - a required one, or one already filled - the draft still comes back, to paste yourself
redo go back to an answer you already gave: it reopens pre-filled so you can edit it (redo salary or redo the skill one picks an earlier one by its words; llm: <what to change> inside it redrafts)
dump save the page as it is right now (DOM, fields, data requests, screenshot) into this session's folder under dumps/apply_dumps/ for inspection and keep waiting; dump 10 waits ten seconds first so you can switch back to the form and open the widget. The Dump button does the same and copies the folder path to your clipboard
skip leave the current field empty (also: leave it, leave blank)
yes / no confirm or refuse a click or checkbox the agent proposes (use yes, not ok)
attach resume open the resume picker by hand (also: cover letter for the letter flow)
paste a URL open that page when the agent is stuck
retry try the model again after an outage
park leave THIS application for later and start the next queued job; nothing is submitted or recorded and the job keeps its place in the shortlist (also: later, skip job)
abort end the session and the rest of the queue (also: stop, cancel)
